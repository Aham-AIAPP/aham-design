# 第三方组件

| 组件 | 用途 | 许可 |
| --- | --- | --- |
| [PptxGenJS](https://github.com/gitbrent/PptxGenJS) | 写出 PPTX | MIT |
| [Playwright](https://github.com/microsoft/playwright) | 在 Chromium 里排版、截图和检查 | Apache-2.0 |
| [python-pptx](https://github.com/scanny/python-pptx) | 读取 PPTX 做视觉检查 | MIT |

以上组件通过 npm 和 pip 安装，不随插件分发。

`assets/html2pptx/components.js` 的图标参照 [Lucide](https://lucide.dev)（ISC 许可）的风格绘制：24 网格、线性、圆角端点。
